RL Orchestration Pipeline

How the multi-agent system operates.

A closed-loop autonomous cycle guided by reinforcement learning to route between specialized agents dynamically.

PHASE 01

Deconstruct Requirement

The Planning Agent extracts parameter constraints, input types, and algorithmic invariants directly from plain English.

PHASE 02

Synthesize Implementation

Coding Agent turns the plan into modular, clean Python with type annotations, following best practice patterns.

PHASE 03

Review & Sandboxed Tests

Review Agent computes quality scores while Testing Agent executes assertions in an isolated Python subprocess.

PHASE 04

Autonomous Self-Repair

If test assertions fail, diagnostic error analysis pinpoints the traceback and patches the solution automatically.

def top_students(students: list[dict]) -> list[dict]:
    """
    Returns the top 3 student records sorted by marks descending.
    Ties broken alphabetically by student name.
    """
    if not students:
        return []
    
    return sorted(
        students,
        key=lambda s: (-s.get("marks", 0), s.get("name", ""))
    )[:3]
